# falagent whiteboard: author notes (2026-09-23)

The board builds the plan as written: seven chapters, erases at 6.34 / 11.68 / 13.02 / 15.16 / 17.86 / 24.10, the same five bespoke objects, the same eight keys all BELOW their objects, the same five connectors, the palette carried across seam 0 and the fal plate walking into the window across seam 5. Where the board departs from the plan text, it is because a law or the shared harness forces it.

1. **FAL AGENT is written at 5.62, not 4.88 (LAW 4 forces this).** The caption canon puts the pill "fal agent." on screen from 4.56 to 5.58. `caption_identity_guard` refused the build because the key term would have appeared while the identical pill was still showing. The key is written at 5.62, which is 0.74 s after the word and inside the label law's 1.0 s window. It is still the first type on the board (LAW 9).
2. **No palette glyph on the outro sheet (harness limit).** The plan puts a small palette on the rising sheet. The shared harness's `outro_block` owns the sheet (rule, handle, daily micro-line) and has no glyph slot. `assert_outro_clear` also refuses any ink authored at or after the outro anchor. Forking the harness is not allowed, so the whiteboard outro is the harness sheet as it stands.
3. **Phone-at boxes are this board's own seats.** The plan's bboxes come from the shared scene's canvas layout and do not match a 576 x 460 marker board. The job's `--phone-at` specs use the same five objects at the whiteboard's own seats, each at a time when the object is complete and the pen has left it.
4. **The palette goes back to the centre at 0.8 scale on seam 0.** This is the plan's "a little smaller". The clapperboard sits on the left and the easel on the right, symmetric about the axis.
5. **The dartboard's twenty wedges are drawn as marker spokes** with alternate wedges hatched between the rings, not solid fills (whiteboard rule: no solid fills). The bull is a terracotta ring. The dart has terracotta flights.
6. **The consistency emphasis** retraces the three frame outlines in terracotta on 'across', as the plan's whiteboard_version says. The model pick is `box_emphasis` on the Gemini tile (LAW 38, drawn tile), on 'the', and it leaves at 12.82.
7. **The comparison THE MODEL / THE PROMPT** is declared to the label law. Both terms are written, in consecutive chapters as the plan decides. No connector joins them because they never share a board. If Miguel wants the contrast drawn as one picture, that would be a plan change: one chapter holding both.
8. **Address bar text** `fal.ai` is set in lowercase JetBrains Mono at 15 u (28 px), because it is UI chrome and not a label. At 10.5 u it could not be read at phone size.
