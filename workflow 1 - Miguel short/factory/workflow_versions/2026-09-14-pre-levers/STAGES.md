# STAGES — the shorts factory stage register

One row per stage, always these columns, numbers are permanent. A retired stage keeps its number and is marked retired; a new stage takes the next number. This file is the map; `STANDARD.md` is the law; `PRODUCTION.md` is the procedure; `LEARNINGS.md` is the ledger. Any change to `.claude/workflows/daily-shorts.js` updates this file in the same commit, and `pipeline/test_stage_register.py` fails when an agent label or a workflow phase has no row here.

Workflow phases (the `/workflows` groups): **Prep** = stages 1-6 · **Production** = 7-13 and 17-18 · **Audit** = 14 · **Deliver** = 15-16.
