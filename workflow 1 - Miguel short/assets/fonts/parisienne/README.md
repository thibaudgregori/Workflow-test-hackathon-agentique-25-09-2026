# Parisienne

Formal, readable copperplate script by Astigmatic. Chosen on 2026-09-25 for names and headings in the Karla & Diego wedding site (replacing Pinyon Script, whose "a" reads as "o" at small sizes, so "Karla" looked like "Karlo" printed on the 3D envelope).

- Source: Google Fonts repository (`ofl/parisienne`), downloaded 2026-09-25.
