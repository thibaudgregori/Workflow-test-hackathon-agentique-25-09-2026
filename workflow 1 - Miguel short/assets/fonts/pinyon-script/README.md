# Pinyon Script

Formal copperplate script. Used for names and headings in the Karla & Diego wedding site design system, and for the "DK" monogram pressed into the 3D wax seal.

- Source: Google Fonts repository (`ofl/pinyonscript`), downloaded 2026-09-25.
