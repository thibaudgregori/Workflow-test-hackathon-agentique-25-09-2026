---
name: No logo outlines on thumbnails
description: Never add white outlines to logos in YouTube thumbnails — user strongly dislikes them
type: feedback
---

When generating personal YouTube thumbnails, NEVER add white outlines to logos. The user is "quite sure" they will never want outlines. The outline functionality has been fully removed from `generate_personal_thumbnail.py`. Logos are placed as-is from their PNG source files.
